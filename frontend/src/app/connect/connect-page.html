How to create a key
  1. Open WebUntis in the browser and log in.
  2. Click your name (top right) → Profil → tab Freigaben.
  3. Next to Zugriff über Schlüssel, click Anzeigen and copy the key.
  4. Paste it above. You can revoke it there at any time.
